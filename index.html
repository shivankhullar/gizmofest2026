Scientific Rationale

Our scientific motivations for this meeting are:

  1. This would be the first-ever GIZMO community meeting, long overdue given the code’s growth and reach.
  2. Multiple branches of the code have diverged significantly; it would be valuable to compare notes, share numerical methods, and explore opportunities to combine methods.
  3. We would like to establish a comprehensive unit-testing framework — a standard suite of tests required for every PR or set of commits — to make catching and fixing bugs faster and more systematic.
  4. As the community moves toward GPU computing, now is the right moment to make informed, collective decisions about the architecture and direction of a GPU-native version.

Programme

The full schedule will be posted here once it is finalised.

Tentative agenda

  • Short (~15 min), tutorial-style talks from attendees on what they have been developing
  • Collaborative unit-test hacking sessions
  • Focused discussion sessions on:
    • Quality-of-life improvements, particularly in the context of the evolving GPU version
    • GPU strategies: methods, optimizations, and portability
    • Load balancing for extreme dynamic range problems
    • Possible architectures for a next-generation code
    • Community communication infrastructure: establishing a dedicated forum or channel to replace the now-dormant Google Group
    • Physics wish-list: what do we want to simulate with GIZMO that is currently out of reach, either because the physics is absent from the main code or is siloed in a single branch?
